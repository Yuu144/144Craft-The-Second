# FreeTerraForged Terrain Debug

Adds the active FreeTerraForged terrain name to the left side of the F3 debug screen.

Requires Minecraft 1.21.1, NeoForge 21.1.248+, and FreeTerraForged 1.0.0027+. Install the built JAR on both the client and dedicated server.

Build from this directory with `gradle build`. The addon compiles against the FreeTerraForged JAR in the parent instance's `mods` directory and does not bundle it.
